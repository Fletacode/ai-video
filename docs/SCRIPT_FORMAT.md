# v3 대본 포맷 규격 (SCRIPT_FORMAT)

`slide_narrator.parse_script` 가 파싱하는 나레이션 대본의 **정식 규격**입니다.
사람(작성자=Claude Code)과 코드(파서)가 공유하는 계약입니다.

connect-ppt 포맷의 **상위호환**입니다: 기존 마커 의미는 그대로이고, `[오디오 태그]` 하나만 추가됩니다.

## 문법

```
Document := (Header Body)*
Header   := "**[" 정수 "]**"                 # 슬라이드 번호. PDF 페이지 N ↔ [N] (1:1)
Body     := (Text | Pause | Bgm | Sfx | Tag)*
Text     := 나레이션 문장 (구어체, 호흡 단위로 분리)
Pause    := "(" 정수 "초동안 쉼,공백)"          # legacy: v3 인라인 쉼 태그로 변환 (실제 무음 아님)
Bgm      := "(배경음악만, 나레이션 없음)"          # 나레이션 없는 무음 슬라이드
Sfx      := "(효과음 " 숫자 "초)"               # 징글(효과음) 삽입 지점. --jingle 음원을 N초로 맞춰 삽입
Tag      := "[" 태그워드 "]"                    # v3 오디오 태그. TTS엔 전달, 자막엔 제거
```

## 요소별 규칙

### 1. 슬라이드 헤더 `**[N]**`
- 슬라이드 1장당 헤더 1개. **PDF 페이지 수와 개수·순서가 정확히 일치**해야 한다.
- 슬라이드는 해당 세그먼트 오디오 길이만큼 화면에 정지 후 다음 장으로 **하드 컷**된다(1:1).
- 슬라이드를 합치거나 나누지 않는다.

### 2. 쉼 태그 (권장) / `(N초동안 쉼,공백)` (legacy)
- **eleven_v3 는 실제 무음(SSML `<break>`)을 지원하지 않는다.** 쉼은 v3 오디오 태그로 표현한다:
  `[short pause]`, `[long pause]`, `[pause]`. 텍스트에 인라인으로 남아 v3 에 전달된다.
- ⚠️ **정확한 초 단위 길이는 보장되지 않는다**(v3 가 문맥에 따라 결정). 정밀한 타이밍이 필요하면
  이 방식으로는 불가능하다.
- **legacy 마커** `(N초동안 쉼,공백)` 은 하위호환을 위해 파서가 자동 변환한다:
  `1초 → [short pause]`, `2초 → [long pause]`, `그 외 → [pause]`.
- 신규 작성은 마커 대신 **쉼 태그를 문맥에 맞게 직접** 배치하는 것을 권장한다
  (작성 절차는 [`AUTHORING_GUIDE.md`](AUTHORING_GUIDE.md) §5).
- **세그먼트 시작·끝에도 쉼 태그를 둔다**(슬라이드 하드 컷 전환 여유).
  시작은 속도 태그 뒤 `[short pause]`, 끝은 `[short pause]`/`[long pause]`
  ([`AUTHORING_GUIDE.md`](AUTHORING_GUIDE.md) §5).
- 세그먼트 본문은 쉼 태그를 포함한 **단일 텍스트**로 합쳐져 **슬라이드당 v3 요청 1회**로 합성된다.

### 3. 무음 슬라이드 `(배경음악만, 나레이션 없음)`
- 나레이션이 없는 슬라이드(표지/전환). 기본 6초 무음(`--default-silent-sec`).

### 4. v3 오디오 태그 `[태그]` (신규)
- 대괄호 토큰이 **텍스트 그대로 eleven_v3 로 전달**되어 감정·전달 방식을 유도한다.
- **자막(SRT)·로그에는 나오지 않는다** (`clean_text` 에서 제거).
- **닫힌 어휘만 사용**한다(임의 태그 생성 금지). 권장 어휘:

| 분류 | 태그 | 용도 | 주의 |
|---|---|---|---|
| 감정 | `[warm]` | 따뜻하고 친근하게(도입/환영) | 남발 금지 |
| 감정 | `[excited]` | 활기차게(정답 공개/강조) | |
| 감정 | `[curious]` | 궁금증 유발(질문 던질 때) | |
| 감정 | `[serious]` | 진지하게(정정/주의) | |
| 감정 | `[reassuring]` | 안심시키듯(격려) | |
| 쉼 | `[short pause]` | 짧은 쉼(≈1초 느낌) | 정확한 초 보장 안 됨 |
| 쉼 | `[long pause]` | 긴 쉼(정답 공개 전 뜸 등) | 정확한 초 보장 안 됨 |
| 쉼 | `[pause]` | 가벼운 호흡 | |
| 전달 | `[whispers]` | 속삭이듯 | |
| 전달 | `[emphasizes]` | 특정 구절 강조 | |
| 속도 | `[slows down]` | 느린 템포로 전환(세그먼트 첫머리 기본 배치) | 배속 옵션 아님·보이스별 편차 |
| 속도 | `[deliberate]` | 또박또박 신중한 낭독(어휘·예문·정답 낭독) | |

- **모든 쉼은 v3 태그**다(실제 무음 아님). 길이는 v3 가 문맥으로 결정하므로 초 단위 정밀 제어는 불가.
  legacy `(N초동안 쉼,공백)` 은 위 쉼 태그로 자동 변환된다.
- **속도 조절도 태그로 한다.** eleven_v3 에는 문서화된 숫자 속도 설정이 없다
  (`voice_settings.speed` 는 다른 모델용). 학습자 대상이므로 **느린 템포가 기본 방침** —
  배치 규칙은 [`AUTHORING_GUIDE.md`](AUTHORING_GUIDE.md) §4.
- 태그는 수식할 구절 **바로 앞**에 둔다. 단어 중간에 넣지 않는다. 호흡 그룹당 감정 태그 1개면 충분.
- 대괄호는 반드시 닫는다. 안 닫으면 자막에 그대로 남아 미리보기에서 발견된다.

### 5. 효과음(징글) 마커 `(효과음 N초)` (신규)
- 원본의 음악 연출 메모(`앤딩 음악 2 (8초) ~~~ '경쾌하게'` 등)를 이 마커로 변환한다. **낭독되지 않는다.**
- 합성 단계에서 별도 음원(`--jingle`, 기본 `assets/jingle.mp3`)을 **정확히 N초**로 맞춰
  (짧으면 반복, 길면 컷+페이드아웃) 해당 지점에 삽입한다. 음원이 없으면 N초 무음으로 대체된다.
- **영상 맨 처음의 오프닝 음악은 별도 음원을 쓴다**: 첫 슬라이드 세그먼트에서 나레이션보다
  앞에 오는 마커는 `--jingle` 대신 `--opening` 음원(기본 `assets/opening.mp3`)이 삽입된다
  (오프닝 음원이 없으면 징글로 대체). 인트로 음악 마커는 첫 세그먼트 **시작**에 둔다.
- **세그먼트 시작 또는 끝에만** 둔다 — 본문 중간에 넣으면 TextRun 이 쪼개져 슬라이드당
  v3 요청이 늘어난다.
- 음악·효과음을 v3 오디오 태그로 표현하지 않는다(`[music]` 등 음성 외 태그 금지).
- 음원 생성: `uv run -m slide_narrator.sfx` (ElevenLabs Sound Effects, 0.1~30초 지정 가능).

## 파서가 하는 일 (보존 vs 제거)

| 입력 | TTS 텍스트(v3로 전달) | 자막(clean_text) |
|---|---|---|
| 일반 텍스트 | 유지 | 유지 |
| `[warm]` 등 태그 | **유지** | **제거** |
| `[short/long pause]` 쉼 태그 | **유지**(인라인) | **제거** |
| `(N초동안 쉼,공백)` (legacy) | `[short/long pause]` 태그로 변환(인라인) | 제거 |
| `(배경음악만…)` | 무음 세그먼트 | 제거 |
| `(효과음 N초)` | **Sfx 런** → 징글 음원을 N초로 맞춰 삽입(음원 없으면 무음) | 제거 |
| `○ △ →` | 동그라미/세모/(제거) | 동그라미/세모/(제거) |

## 예시 (3슬라이드)

```
**[1]** (배경음악만, 나레이션 없음)

**[2]** (2초동안 쉼,공백) [slows down] [warm] 자, 이번 제1과에서는요, [pause] 만나고 헤어질 때
쓰는 기본 인사말을 같이 배워볼 거예요. [excited] 어렵지 않으니까 편하게 따라오세요. [short pause]

**[3]** [slows down] [short pause] [warm] 오늘의 목표는요, 시간이랑 일상 표현을 중심으로 [pause] 기본적인 한국어를
자연스럽게 말하는 거예요. (1초동안 쉼,공백) 그럼 하나씩 살펴볼까요? [short pause] (효과음 8초)
```

- `[2]`의 **자막**: `자, 이번 제1과에서는요, 만나고 헤어질 때 쓰는 기본 인사말을 같이 배워볼 거예요. 어렵지 않으니까 편하게 따라오세요.` (태그·쉼 모두 제거)
- `[2]`의 **v3 전달 텍스트**: 위 문장에 `[slows down] [warm] [pause] [excited] [short pause]` 가 그대로 포함되고, `(2초동안 쉼,공백)` 은 `[long pause]` 로 변환되어 인라인으로 남는다. 세그먼트 전체가 **v3 요청 1회**로 합성된다.
- `[3]` 끝의 `(효과음 8초)` 는 나레이션이 끝난 뒤 징글 음원이 8초 붙는다(자막에는 안 나옴). 슬라이드는 그 8초 동안 화면에 더 머문다.
